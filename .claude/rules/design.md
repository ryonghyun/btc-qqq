# 디자인
- 발표 슬라이드(PPT)처럼 디자인한다.
- 스타일은 Pico CSS v2를 쓰고, 직접 작성하는 CSS는 최소화한다. 분석이 중심이므로 시각화와 사용성 외의 디자인에는 시간과 토큰을 쓰지 않기 위해서다.
- 모바일 친화적(mobile-friendly)이어야 한다.
- 목차를 내비게이션(navigation)으로 제공한다. 데스크톱에서는 상단 내비게이션(top navigation bar), 모바일에서는 하단 내비게이션(bottom navigation bar)으로 배치한다.
- 내비게이션에는 큰 단위(섹션)만 표시하고, 섹션 안의 슬라이드는 위아래로 넘긴다(vertical scroll/swipe).
