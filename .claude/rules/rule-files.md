# 규칙 파일 관리
- 이 규칙은 데이터를 인터랙티브하게 분석하고 시각화하는 웹을 만드는 여러 프로젝트가 함께 쓴다. 특정 프로젝트 전용 규칙이 아니다.
- `.claude/rules/`는 https://github.com/ryonghyun/rules-for-iavb 저장소를 git subtree(`--squash`)로 넣어 관리한다.
- 규칙과 Claude Code 설정은 모두 프로젝트 안(`.claude/`)에서 관리하고, 사용자 설정(`~/.claude/`)이나 auto memory에 두지 않는다. 여러 컴퓨터를 옮겨 다니며 작업하는데, 프로젝트 밖의 파일은 다른 컴퓨터로 따라오지 않기 때문이다.
- 규칙 파일에는 규칙만 쓴다. 진행 상황이나 할 일은 시간이 지나면 낡아서 규칙과 섞이면 헷갈리기 때문이다.
- 규칙 파일에는 일반 원칙만 쓴다. 한 프로젝트에만 해당하는 값, 공식, 변수 이름은 그 프로젝트의 README에 쓴다.
- 규칙 사용법(넣기, 받기, 올리기)은 `README.markdown`에 쓴다. 확장자가 `.md`가 아니어서 규칙으로 읽히지 않으면서 GitHub에서는 Markdown으로 보이기 때문이다.
