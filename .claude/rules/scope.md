# 작업 범위
- 이 프로젝트 폴더 밖(다른 프로젝트, 홈 폴더, 사용자 설정 `~/.claude/`)은 찾아보지도, 읽지도, 바꾸지도 않는다. Bash 명령(`ls`, `find`, `grep`, `cat` 등)으로 접근하는 것도 마찬가지다. 다른 프로젝트나 개인 파일의 내용이 이 작업에 섞이거나, 사용자 설정이 모르게 바뀌는 것을 막기 위해서다.
- 예외: Claude Code가 이 세션에 마련한 임시 폴더(scratchpad)는 읽고 쓸 수 있다. 도구 출력이 길어서 Claude Code가 따로 저장한 이 세션의 출력 파일은 읽을 수 있다.
- 그 밖에 폴더 밖 접근이 꼭 필요하면 이유를 말하고 먼저 묻는다.
- Claude Code 설정을 바꿀 때는 범위(scope)를 사용자(user), 프로젝트(project), 로컬(local) 중 어디로 할지 확인한다.
